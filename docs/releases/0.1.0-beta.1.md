# PanganKita v0.1.0-beta.1 (Android testing)

**Prerelease:** Non-commercial educational and research prototype testing only.
This APK is not a production food-ordering or payment service.

## What's included

- Android customer-facing demonstration screens, sample merchant and food
  listings, preview cart, checkout and order flows
- Indonesian, English and Simplified Chinese interface support
- Local navigation, UI validation and sample interaction flows

## Known limitations

- No real authentication, merchant verification or account recovery
- No live availability, inventory reservation, ordering or payment processing
- No live GPS, maps, messages, delivery dispatch or pickup confirmations
- Sample pricing, merchant details, locations and user activity are illustrative
- Do not provide real credentials, payment information or private data
- Example menu or food photographs may belong to third parties; no affiliation
  or endorsement is implied

## Installation and verification

Download the attached `PanganKita-v0.1.0-beta.1.apk` and check its SHA-256
hash against `SHA256SUMS` before installing. Install only if you trust the
publisher and signing certificate. Test on Android devices compatible with
the repository's current SDK baseline. Report non-sensitive issues via
[GitHub Issues](https://github.com/PanganKita-Labs/android/issues).
