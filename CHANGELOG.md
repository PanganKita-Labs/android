# Changelog

Noteworthy changes to PanganKita Android are recorded here. Entries follow
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) conventions;
versions use [Semantic Versioning](https://semver.org/).

**Release status:** The first Android beta is being prepared. No release
is published merely because this file or a release-notes draft exists.
Maintainers update this history when a version is actually released.

## [Unreleased]

### Added

- Prepared the Android `v0.1.0-beta.1` testing prerelease workflow with
  manual approval, signed APK preparation, checksums and draft publication.
- Documented Apache-2.0 code licensing, contributor and maintainer attribution,
  third-party asset review, and responsible AI-assisted contributions.
- Welcomed documentation, accessibility, research and internationalization
  contributions for the Indonesia-first Flutter demonstration.

### Notes

- The app remains a local, fixture-backed educational and research prototype.
  It does not support live authentication, merchant listings, inventory
  reservations, payments or pickup confirmations.
- Publication is blocked until application identity, signing, legal rights,
  asset permissions and real-device checks are complete.
- See the [release checklist](docs/RELEASING.md) and
  [proposed beta tester notes](docs/releases/0.1.0-beta.1.md).
